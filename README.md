An entry for make.fun's [The Excuse That Almost Works](https://make.fun/bounty/u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5) bounty ($2 in USDC): a program that writes the one line a gamer texts the boss to skip work on GTA 6 launch week — at most 20 words, one line, plain text.

`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`. The excuse is a real, specific, boring detail — roadworks cut the power — and the laugh comes from its own logic: the phone is on 4%, so the text has to be short, which is exactly why the excuse itself is one hurried line. No GTA mention, no dead grandmother, no flat tyre, no sudden fever: a tired manager has heard all of those twice. The output is deterministic: every run writes the same line, 81 characters and 16 words, inside the gate (1 line, 1–140 characters, at most 20 words).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
